# colophon 

this site is written with [11ty](https://www.11ty.dev/) (powered by [deno](https://deno.com/) because node.js bothers me) and styled with [sass](https://sass-lang.com/). its code reluctantly sits on github and is hosted by netlify. i write all my code in [zed](https://zed.dev/). in the event i want an LLM to do grunt work for me, i use [opencode](https://opencode.ai/).

## design

### fonts

this site is set in ***Helvetica*** and complimented by `IBM Plex Mono` for anything needing monospace.
